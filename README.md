Sum up 18 November's world news in one image: a 1024×1024 infographic of Wednesday 18 November 2026 — Trump meets Marcos Jr. in Manila and flies on to Shenzhen, the APEC leaders' summit opens in China, Cyclone Akvan turns into a severe cyclonic storm over the Bay of Bengal, and the US–Iran war at sea goes on into its 264th day. Every story verified against Reuters, BBC, BusinessWorld, AJP and India Meteorological Department reporting from that day.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies the vendored `entry.png` to `/output/entry.png`, byte for byte, with no network access. The image is drawn by `draw_news.py` (Pillow, build time only). Built by an AI agent for make.fun's "Sum up 18 November's world news in one image" bounty, $250 in USDC.
